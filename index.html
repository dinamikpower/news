Χρειάζεται JavaScript για να εμφανιστούν οι ειδήσεις.

Αυτόματη καθημερινή περίληψη στα ελληνικά, γραμμένη από τεχνητή νοημοσύνη (Claude) με βάση δημοσιευμένες πηγές, που αναφέρονται κάτω από κάθε θέμα. Δεν αντικαθιστά τις ίδιες τις πηγές και μπορεί να περιέχει λάθη ή παραλείψεις. Για κάτι σημαντικό, έλεγξε την αρχική πηγή. Οι ιατρικές ειδήσεις δεν αποτελούν ιατρική συμβουλή.
