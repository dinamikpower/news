# Πρωινή Ενημέρωση

Στατικό site με καθημερινή περίληψη ειδήσεων στα ελληνικά (γεωπολιτική, οικονομία, τεχνολογία, επιστήμη, ιατρική, αρχαιολογία).

- `index.html`: ολόκληρο το site (χωρίς build)
- `data/index.json`: λίστα ημερών, `data/YYYY-MM-DD.json`: περιεχόμενο κάθε ημέρας
- Κάθε πρωί η προγραμματισμένη εργασία προσθέτει ένα νέο `data/<ημερομηνία>.json` και ενημερώνει το `data/index.json`.
